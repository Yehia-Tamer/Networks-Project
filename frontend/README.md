# Frontend (React + Vite)

```
cd frontend
npm install
copy .env.example .env      # then set VITE_API_URL to your laptop's Wi-Fi IP, port 8000
npm run dev                 # opens on http://<laptop-ip>:5173 for the phones
```

Routes so far: `/login`, `/register`, `/metrics` (Eyad).
Gelan's `ChatList` and Maryam's `ChatWindow` plug into `src/App.jsx` (lines are already there, commented out).
